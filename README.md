# DoujinPOS PWA v0.2.1

iPadのSafariからホーム画面へ追加して使う、同人CD向けの即売レジ／在庫管理／試聴PWAです。Mac・Xcodeは不要です。

## v0.2でできること

- Google Sheetsから書き出した在庫CSVの取込
- 管理画面から商品の追加・編集・削除
- 在庫表の行タップから「±1 / 在庫数指定 / 販売停止・再開」を即操作
- 商品ジャケットをタップしてカート追加
- 現金／その他決済で会計
- 会計時の在庫自動減算
- 販売履歴と在庫移動履歴の端末内保存
- 現在庫CSV／販売履歴CSV／在庫移動CSVの書出し
- 商品ごとのジャケット、XFD音源、MV動画の端末内保存
- XFDの常駐プレイヤー再生
- MVのアプリ内再生
- PWA化後のオフライン起動

## 在庫原票

`inventory_master_template.csv` と同じ列でGoogle Sheetsを作るのが簡単です。最低限必要な列は次の4つです。

- 商品ID
- タイトル
- 頒布価格
- 現在庫

商品IDは一度決めたら変更しない固定IDにしてください。CSV取込時、同じ商品IDがあれば価格・タイトル・在庫などを更新します。在庫差分は「原票同期」として在庫移動履歴に残します。

## iPadで使うまで

PWAのService Workerは `file://` 直開きでは動かないため、このフォルダをHTTPSで公開します。ビルド作業は不要です。

### 一番簡単な公開例

- GitHub Pages
- Cloudflare Pages
- Netlify

いずれもこのフォルダの中身をそのまま静的サイトとして公開できます。

公開URLをiPadのSafariで開き、共有ボタン → 「ホーム画面に追加」を選びます。以後はホーム画面のDoujinPOSから起動します。


## v0.1からGitHub Pagesを更新する場合

リポジトリ直下へv0.2の `index.html` / `app.js` / `styles.css` / `sw.js` / `README.md` を上書きアップロードしてください。`icons` と `manifest.webmanifest` はそのままでも動きます。

既存のiPad内データはIndexedDBに残るため、通常は商品・販売履歴・保存済みメディアを消さずに更新できます。更新直後に古い画面が残る場合は、ホーム画面のDoujinPOSを一度終了して再度開いてください。

## イベント当日の運用

1. Google Sheetsの在庫原票をCSVで保存
2. DoujinPOSの「管理」→「在庫原票」からCSV取込
3. 必要なら「試聴/MV」でジャケット、XFD、MVを紐づけ
4. レジ画面で販売
5. 終了後に「販売履歴CSV」「在庫移動CSV」「現在庫CSV」を書出し
6. Google Sheets側へ反映

イベント中はiPad内のIndexedDBが正本です。ネット接続が切れても販売処理は端末内で完結します。

## メディア保存について

ジャケット画像・XFD音源・MVはIndexedDBへBlobとして保存します。Safariのサイトデータを削除すると消えるため、元ファイルは別途保管してください。大容量MVを多数保存するとiPadのサイトストレージを圧迫します。実運用ではXFDは圧縮音源、MVは720p程度の軽量版を推奨します。

## 注意

- 会計取消・セット商品在庫連動・XFDチャプター・複数端末同期は未実装です。
- iPadOS側のストレージ整理や「履歴とWebサイトデータを消去」で端末内データが失われる可能性があります。イベント終了時のCSV書出しを推奨します。
